Week 2 Example 2: Platformer with Platforms Array

Project Title: Celeste Floor is Lava

Setup and Interaction Instructions: 

Open the link from your browser to play the game.

Quickly using the moving platforms get to the top of the game where the strawberry is before the rising lava catches you. 

Controls:
Move left: A or left arrow
Move right: D or right arrow
Jump: w or up arrow
